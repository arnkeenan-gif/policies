Open this page in Safari on the iPhone, then tap:

Install Songspot

Tap Install when iOS asks. The icon appears on the Home Screen and downloads in the background.

  1. If iOS won't open the app, turn on Developer Mode: Settings → Privacy & Security → Developer Mode, then restart the phone.
  2. If it says the developer isn't trusted: Settings → General → VPN & Device Management → trust the profile.
  3. This build shows Google's test ads instead of real ones.

Only installs on iPhones registered to the developer account.
